## 需求

在 `D:\Qt_\learn_demo\lab01_timer\` 新建工程，实现一个窗口：

1. 标题 `Lab 01 - Timer`，大小约 `460 x 300`；
2. **大号时间标签**：每 100ms 刷新一次，显示 `HH:mm:ss.zzz`；
3. **运行时长标签**：用 `QElapsedTimer` 显示自程序启动以来经过的毫秒数；
4. **状态标签**：默认“运行中”；
5. **“暂停/继续”按钮**：
   - 点击后停止/启动日期定时器；
   - 暂停时按钮文字变“继续”，状态标签变“已暂停：界面仍可响应”；
   - 暂停期间按钮仍然可以点击（证明事件循环没被阻塞）；
6. **“2 秒后提醒”按钮**：
   - 点击后状态显示“2 秒后提醒…”；
   - 2 秒后变成“提醒：2 秒到！”；
   - 再过 2 秒恢复“就绪”；
   - 用 `QTimer::singleShot` 实现，不要用 `sleep`；
7. **退出日志**：连接 `aboutToQuit`，用 `qInfo()` 打印 `aboutToQuit: 正常退出`；
8. 所有控件和定时器都必须设置父对象（`this`），不手动 `delete`；
9. 构建 0 warning。

## 可选实验（强烈建议做一次）

临时加一个“阻塞 3 秒”按钮：点击后在槽里先更新状态标签，再调用 `QThread::sleep(3)`（需要 `#include <QThread>`），直接在 UI 线程睡觉。

点击后观察：

- 窗口标题栏变“未响应”；
- 按钮不响应、窗口不重绘；
- 状态标签的“阻塞中…”**在 3 秒内根本不会显示**——因为重绘事件也排在事件队列里。

实验完把这个按钮删掉。这个体验比任何文字解释都直观。
