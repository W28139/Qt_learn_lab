# Lab 01：定时刷新与暂停面板

## 需求

1. 窗口标题 `Lab 01 - Timer`，大小约 `460 x 300`。
2. 大号时间标签每 100ms 刷新 `HH:mm:ss.zzz`；运行时长标签用 `QElapsedTimer` 显示启动至今的毫秒数。
3. 状态标签默认“运行中”。
4. “暂停/继续”按钮：暂停时停日期定时器，按钮文字变“继续”，状态显示“已暂停：界面仍可响应”；暂停期间按钮仍可点击。
5. “2 秒后提醒”按钮：用 `QTimer::singleShot`，2 秒后显示“提醒：2 秒到！”，再过 2 秒恢复“就绪”，不能用 `sleep`。
6. 连接 `aboutToQuit`，用 `qInfo()` 打印 `aboutToQuit: 正常退出`。
7. 控件和定时器都设置父对象，不手动 delete；构建 0 warning。

## 可选实验

点击后先更新状态标签，再调用 `QThread::sleep(3)`，观察窗口“未响应”、标签不重绘，做完删除。

## 验收

- [ ] 时间每 100ms 左右刷新；
- [ ] 暂停后时间停止，按钮仍能立即响应；继续后运行时长跳到真实值；
- [ ] 提醒的“2 秒 → 再 2 秒”流程正确；
- [ ] 退出时应用程序输出中有 `aboutToQuit: 正常退出`；
- [ ] 重复运行、关闭无崩溃，0 warning。
