# Lab 00：第一个 Qt 6 窗口

确认 Kit、CMake、Qt 版本正确，能独立创建并运行一个 Qt 6 Widgets 工程。

## 需求

1. 在本目录创建 CMake 工程 `lab00_hello`，用 Qt Creator 打开 `CMakeLists.txt`，选择 Desktop Qt 6.8.x Kit。
2. 写一个窗口，标题 `Lab00 <版本>`，版本 `0.1.0`，大小 `520 x 260`，文字居中。
3. 窗口上显示运行时 Qt 版本，确认与编译时版本一致。
4. 实验：临时把 `return app.exec();` 改成 `return 0;`，观察窗口行为，再改回。

## 验收

- [ ] 构建成功，0 warning；
- [ ] 窗口正常显示，标题 `Lab00 0.1.0`，大小正确；
- [ ] 运行时与编译时 Qt 版本一致，均为 6.x；
- [ ] C++ 标准 ≥ `202002L`；
- [ ] 去掉 `exec()` 后窗口一闪而过，能解释原因；
- [ ] 关闭窗口后进程正常退出。
